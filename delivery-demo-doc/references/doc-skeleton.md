# 文档骨架（五章，固定顺序）

## 封面区
标题（{系统名} 专业交付手册 · {业务对象}全流程操作闭环）+ 副题一句话 + 信息条：适用对象（使用方 + 甲方功能验收人员）/ 测试环境 / 测试账号 / 版本日期。导航页签五章。

## ① 主线沙盘
- 站点条：6-10 站，可点击；每站含序号、中文名、界面语言名
- 状态跟踪器：当前状态徽章、关键标识（如工单号/渠道）、SLA 计时说明、进度条、上一站/下一站
- 主角故事卡：一个虚构居民/客户 + 一句话诉求（贯穿全文）
- 每站固定内容：
  1. 角色代入卡（现在你是：{角色}）
  2. 界面操作（编号步骤 + 真实按钮）
  3. 系统在做什么（行为与规则，不写代码）
  4. 名词与功能（术语卡，一句话）
  5. 常见问题（折叠，"常见问题：…"格式，≥2 个）
  6. 闭环去向（黄底标注条）

## ② 支线回路
每条支线一张卡：触发 → 操作 → 系统规则 → 回到主线第几站；附 1-2 个常见问题。必查类型：兜底、挂起、升级、超时、特殊件、回退。

## ③ 角色速查
页签式，每角色四行表：每天怎么开始 / 高频按钮 / 不能做的事 / 常见问题。不含系统维护角色。

## ④ 系统功能说明
- 功能卡网格（F01…Fn，≥12 张为宜）：功能定义 / 使用场景 / 功能确认三段，标注对应站点
- 功能确认清单表：☐ ｜ 功能 ｜ 确认方式 ｜ 对应位置

## ⑤ 环境说明与功能确认清单
- 环境与账号表：测试环境、测试账号、预置示例数据、参数说明
- 要点回顾（三项清楚 = 已掌握闭环）
- 全流程确认清单：检查点 ｜ 操作 ｜ 系统表现 ｜ 闭环去向
- 阅读建议（面向读者，不面向讲解人）

## 交互组件要求（HTML）
- 站点导航与面板切换（点站点、上一站/下一站）
- 状态跟踪器随站点更新（状态名、SLA 说明、进度条）
- 角色页签切换
- 折叠问答（details）
- 打印样式：隐藏导航按钮、全部站点与页签展开
